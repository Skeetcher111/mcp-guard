# Как помочь проекту

- Нашли шпионское приложение, которого нет в базе, или ложное срабатывание — откройте issue по шаблону, укажите имя пакета.
- Код: форк, ветка, `npm install`, `npm test`, затем pull request с коротким описанием, что и зачем.
- Базы угроз собирает `scripts/build-data.py`, руками JSON в `src/data` не правьте.

## English

Found a missing stalkerware package or a false positive? Open an issue with the package name. For code: fork, `npm install`, `npm test`, send a PR.
